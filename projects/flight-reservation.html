Flight Reservation

A WinForms flight booking app, built to demonstrate backend fundamentals — event-driven programming, data validation, and clean structure — with design deliberately kept out of the way.

Role

Software developer

Timeline

2 weeks (1.5 weeks development)

Tools

  • Visual Studio
  • C#
  • Figma

Overview

This was an individual skill-growth project, not a client engagement — the goal was to showcase backend programming ability rather than visual design. The app handles flight bookings through a Windows Forms interface, with dynamic form elements, efficient event handling, and validation built with regular expressions to keep data reliable.

Process

  • Wireframes: pen sketches translated into low-fidelity wireframes in Figma to plan layout — not to ideate design direction, since the flow itself was already defined before development started.
  • Usability testing: conducted informally with colleagues rather than end users, since the focus was backend skill growth, not UX validation.
  • UI: given only enough attention for clean spacing and logical element ordering — intentionally not a design showcase.

Learnings

Building this reinforced how much meticulous, defensive coding matters even in a small desktop app — regex validation and event handling have to hold up under real (if informal) user interaction. It also made clear that "user-focused" thinking applies to backend work too, not just interfaces.
